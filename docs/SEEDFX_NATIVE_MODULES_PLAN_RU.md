# Следующий формат SeedFX: исполняемые модули на microSD

Статус: проектирование; не выдавать существующий `.sfx` v1 за исполняемый
модуль. Сначала устранена нехватка DMA-памяти P4 при работе педалборда.

## Контракт хранения

- Один пакет эффекта содержит собственный Cortex-M7 Thumb-2 hard-float код,
  описание параметров, mono/stereo-разъёмы, оформление и ресурсы.
- Пресет содержит экземпляры, значения и связи, а не копии кода эффектов.
- Каталог на карте может содержать 1000+ пакетов. P4 читает метаданные
  постранично в PSRAM; не создаёт одновременно тысячи LVGL-объектов.
- Seed3 загружает только код и ресурсы активного графа. Несколько экземпляров
  одного модуля делят неизменяемый код, но имеют независимое состояние.
- Количество одновременно исполняемых нод ограничивается временем аудиоблока
  и RAM, отдельно от количества пакетов, хранящихся на карте.

## Границы библиотек

1. `seedfx_module` — ABI, заголовок образа, проверка и relocation-загрузчик.
   Нельзя просто вызывать BIN, слинкованный для flash по фиксированному адресу.
2. `seedfx_runtime` — размещение кода/состояния в SDRAM, таблица загруженных
   модулей, refcount, проверка бюджета нового графа и атомарное включение.
3. `p4_seedfx_storage` — индекс каталога, чтение/проверка пакетов, потоковая
   передача только недостающих модулей по управляющему каналу.
4. SDK упаковки — сборка отдельного эффекта ARM-toolchain, проверка импорта,
   упаковка кода/метаданных/ресурсов и воспроизводимые тесты.

## Минимальный ABI

Модуль объявляет версию ABI, размер/выравнивание состояния, количество входов
и выходов, параметры, требуемую память и поддерживаемые частоты. Движок
предоставляет `prepare`, `process`, `reset`/`release` и таблицу разрешённых
математических функций. `process` получает указатели аудиобуферов, число
frames и непрерывный state; никаких файлов, malloc, mutex или printf.

Проверяются архитектура, версии, арифметика размеров, CRC, смещения entry
points, таблица релокаций, типы разрешённых импортов и требования памяти.
После записи кода нужны согласование D-cache/I-cache и барьеры Cortex-M7.
Подготовка/загрузка выполняются вне audio ISR; до полного успеха продолжает
работать предыдущий граф. Ошибка SD/UART/CRC не должна разрушать текущий звук.

CRC обнаруживает повреждение, но **не делает произвольный машинный код
безопасным**. Нативный модуль выполняется на том же MCU и способен вызвать
HardFault или нарушить сроки аудио. Первая версия поддерживает только
доверенные модули, собранные проверенным SDK; это не защищённая песочница.

## Проверка перед переходом

1. Один внешний Gain: его DSP-реализации нет в ELF основной прошивки; при
   изменении пакета на SD результат меняется без перепрошивки Seed3.
2. Два экземпляра Delay: общий образ кода, независимые состояния/хвосты.
3. Отказы: битый CRC, неподдерживаемый ABI, неверная релокация, нехватка RAM,
   снятие карты, прерванная передача и перезапуск Seed3.
4. Каталог 1000+ записей, ограниченный размер страницы/памяти P4.
5. Реальные 44,1/48/88,2/96 кГц, USB 2×2, смена пресета и контроль deadline.

Увеличивать `SEEDFX_MAX_NODES` без переработки фиксированных delay banks и
wire-формата нельзя: сейчас эти размеры связаны. Миграция требует новой
версии формата, а не удаления проверок границ.
