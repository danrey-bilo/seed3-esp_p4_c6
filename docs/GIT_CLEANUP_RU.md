# Чистая основная ветка master

18.09.2026 по запросу владельца основная ветка `master` приведена к чистому
опубликованному снимку v0.2 (`1a587cb`), затем добавлено это описание.
Рабочие файлы прежнего `master` (`90185a9`) и снимка **полностью совпадали**.
Изменена локальная цепочка коммитов, а не исходники или прошивки.

Восемь старых неопубликованных коммитов с revert/reapply и крупными WAV
сохранены в полном локальном Git bundle. Архив проверен `git bundle verify`;
он содержит `refs/heads/master` на `90185a9a422effa1341c646ee658156e553ed800`
и всю предшествующую историю без внешних prerequisites.

`origin/master` обновлён обычным fast-forward поверх `ee0b5b5`.
Опубликованная общая история не переписывалась; force-push, `reset --hard`
и удаление рабочих файлов не использовались. Основная ветка остаётся `master`.

## Что было очищено ранее

- `6f9824a`: из индекса убраны 286 воспроизводимых WAV, около 243 MiB.
  Записи остаются на диске и доступны в старой истории.
- `5621320`: из индекса убраны семь старых экспериментальных BIN (I2S/SAI и
  тесты DFU suffix). Локальные файлы также сохранены.
- В `.gitignore` добавлены сырые записи и временная диагностика. Актуальные
  образы обеих плат, SHA-256, исходники и компактные отчёты остаются в Git.
- Снимок библиотеки v0.1 сохранён без изменения; новая версия лежит отдельно.

В старых неопубликованных исходных коммитах присутствует WAV размером
115 584 068 байт. Удаление из нового дерева не удаляет его из истории;
обычный push этой цепочки в GitHub превысит ограничение размера одного файла.

Сначала чистый снимок был опубликован в `codex/uac2-v2`. Теперь этот же
коммит входит в `master`; отдельная ветка сохранена как указатель на проверенный
снимок. Большого WAV среди новых объектов опубликованной истории нет.
Исходные WAV остаются на диске и в архиве, не загружаются на GitHub.

## Где лежит резервная копия

Локальный путь относительно корня репозитория:
`.git/local-backups/master-before-cleanup-20260918.bundle`.
Размер: **259 645 529 байт** (около 248 MiB). Архив не входит в GitHub и не
попадает в обычные push. Не удаляйте его, если нужна старая история.

Проверка и восстановление старой цепочки в **отдельную** ветку без замены master:

```powershell
git bundle verify .git/local-backups/master-before-cleanup-20260918.bundle
git fetch .git/local-backups/master-before-cleanup-20260918.bundle refs/heads/master:refs/heads/archive/master-before-cleanup
```

Не объединяйте восстановленную архивную ветку обратно в публикуемый master:
это снова сделает большой WAV частью его истории. Для просмотра её можно
открыть отдельно. Текущий master не требует Git LFS и не содержит восьми
старых исходящих коммитов.
