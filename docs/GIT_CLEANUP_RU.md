# Очистка и публикация v0.2

Исходная локальная история сохранена в ветке `master`; исходная точка работ —
`98410b7`. Никакого `reset --hard`, переписывания этой истории или force-push
не выполняется.

- `6f9824a`: из индекса убраны 286 воспроизводимых WAV, около 243 MiB.
  Записи остаются на диске и доступны в старой истории.
- `5621320`: из индекса убраны семь старых экспериментальных BIN (I2S/SAI и
  тесты DFU suffix). Локальные файлы также сохранены.
- В `.gitignore` добавлены сырые записи и временная диагностика. Актуальные
  образы обеих плат, SHA-256, исходники и компактные отчёты остаются в Git.
- Снимок библиотеки v0.1 сохранён без изменения; новая версия лежит отдельно.

В ещё не опубликованных исходных коммитах присутствует WAV размером
115 584 068 байт. Удаление из нового дерева не удаляет его из истории;
обычный push этой цепочки в GitHub превысит ограничение размера одного файла.

Для публикации используется новая ветка `codex/uac2-v2`: один чистый снимок
итогового дерева поверх существующего `origin/master` (`ee0b5b5` на момент
подготовки). Этот снимок не имеет большого WAV среди новых объектов истории.
Локальный `master` с исходной цепочкой и отдельным коммитом доработки сохраняется.
Удалённый `master` не меняется. Исходные WAV не уничтожаются и не загружаются.

Не отправляйте старую локальную ветку `master` обычным push, пока отдельно
не решён вопрос её крупного исторического объекта. Текущая публикационная
ветка не требует Git LFS или переписывания общих коммитов.
