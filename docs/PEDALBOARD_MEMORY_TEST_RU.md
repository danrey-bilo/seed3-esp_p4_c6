# Перезагрузка при добавлении педалей: 19 сентября 2026

## Воспроизведение

Пользователь последовательно добавлял педали через GT911. После передачи
пятой ноды (`revision=6 nodes=5`, Seed ответил `OK`) P4 выдал:

```text
E (452591) spi_master: setup_dma_priv_buffer(1214): Failed to allocate priv RX buffer
Guru Meditation Error: Core 1 panic'ed (Load access fault).
MTVAL: 0x00000000
```

Перед сбоем SPI CRC/sequence/header errors были нулевыми. Недостаток памяти
подтверждён для **внутреннего DMA heap P4**, а не для 64 МБ SDRAM Seed3.
В ESP-IDF 5.5.5 файл `components/esp_driver_spi/src/gpspi/spi_master.c`
проверяет выравнивание длины RX по cache line. Кадр 544 байта вызывает
выделение временного DMA-буфера. LVGL использовала общий libc malloc и
конкурировала с ним за внутреннюю SRAM. При отказе выделения последующая
очистка приватного дескриптора в драйвере допускает копирование из NULL.

## Исправление

- Отдельный компонент `p4_lvgl_memory` размещает LVGL в PSRAM без fallback
  во внутренний heap.
- Резерв внутренней памяти увеличен с 32 до 64 КиБ.
- SPI wire-format, частота SPI и USB-дескрипторы не изменены.
- Отключённые физические каналы и их соединения скрываются на педалборде.
- Исправлено сохранение ID ноды при Replace, чтобы её рёбра не терялись.

## Проверки

На ПК: 240 добавлений и удалений через реальные обработчики с отрисовкой
каждого состояния; отказ от 13-й ноды без выхода за границы; все 16 масок
физических каналов; четыре независимые крутилки; 100 открытий/закрытий
редактора. DSP-тесты: 40 алгоритмов, влияние 14 добавленных параметров,
выбор mono-входа, сохранение хвоста задержки. Три теста упаковщика — PASS.

На ESP32-P4 rev1.3 после прошивки:

```text
board nodes=6  heap=29875779 largest=29360128 internal=181807 stack=2160
board nodes=12 heap=29865623 largest=29360128 internal=181807 stack=2160
board stress PASS: 10 cycles 0..12..0; original board restored; DSP unchanged
spi=3344 err=0 frame_err[h/c/s/f]=0/0/0/0
```

240 перерисовок за примерно 48 секунд, 10 достижений 12 педалей. Повторные
пики в 12 нод не показали накопления выделенной памяти. Свободная внутренняя
память 181807 байт, запас стека текущей LVGL-задачи 2160 байт. Значения heap
сняты после перестроения объектов, не являются непрерывным измерением пиков.

Этот прогон проверяет интерфейс при работающем LOCAL/SPI-телеметрическом
режиме 48 кГц. Он **не запускает 12 тяжёлых DSP одновременно**, не заменяет
аудиозапись и не является проверкой USB full-duplex под нагрузкой.
