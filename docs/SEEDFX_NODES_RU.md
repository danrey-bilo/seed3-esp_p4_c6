# SeedFX: ноды, граф и microSD

## Что хранится где

- microSD — постоянная библиотека эффектов и пресетов.
- ESP32-P4 — интерфейс, чтение каталога и отправка выбранного графа.
- Внутренняя flash STM32 — текущая прошивка и встроенные DSP-алгоритмы.
- Seed3 QSPI 8 МБ — свободный энергонезависимый уровень для будущего hot-cache;
  текущая версия намеренно не дублирует туда содержимое microSD.
- Seed3 SDRAM 64 МБ — 62 МБ зарезервированы движком: примерно 44,4 МБ доступны
  проверенному кэшу пакетов/ресурсов, ещё 17,6 МБ — двум независимым банкам
  задержек active/staging-графов. 2 МБ оставлены другим подсистемам.
- Внутренняя SRAM Seed3 — два компактных active/staging-графа и аудиобуферы.

**Статус пакета эффекта `.sfx` v1:** он пока выбирает DSP-процессор в прошивке
и передаёт параметры. Это временная реализация, а не целевая архитектура.
Требование следующего формата — хранить исполняемый Cortex-M7-код эффекта,
параметры и описание разъёмов на карте, загружая только активные модули в RAM.
Загрузчик машинного кода ещё не реализован; существующие файлы нельзя считать
исполняемыми плагинами. Каталог из 1000+ модулей также пока не поддерживается.
Порядок миграции и проверки — [план нативных модулей](SEEDFX_NATIVE_MODULES_PLAN_RU.md).

## Организация файлов

Один тип эффекта хранится в одном `.sfx`. Это удобно обновлять и кэшировать.
Один пресет `.sfg` содержит много экземпляров нод и их соединения. Поэтому
десять Gain-нод не требуют десяти копий пакета Gain: пакет загружается один
раз, а граф содержит десять маленьких описаний экземпляров.

Готовый образ находится в `microSD-ready`. На FAT32-карту копируется папка
`SEEDFX` целиком. JSON — читаемый исходник; `.sfx` и `.sfg` — проверяемый
бинарный формат для прошивки.

Пересборка файлов:

```powershell
python tools/seedfx_pack.py --root microSD-ready/SEEDFX
```

## Безопасное применение графа на Seed3

1. P4 отправляет пакет по UART, не меняя SPI-аудиопротокол.
2. Seed3 проверяет magic, версию, длины, CRC, ID нод, типы, рёбра и отсутствие
   циклов.
3. Новый граф полностью строится в staging-слоте вне аудиопрерывания.
4. На следующей границе 32-сэмплового блока active/staging меняются атомарно.
5. В аудиоколбэке нет `malloc`, файловой системы, UART, форматирования строк
   или блокировок.

Движок содержит 42 mono/stereo-профиля: служебные ноды, drive/lo-fi, фильтры,
tone, dynamics, tremolo/auto-pan/ring-mod, delay/ping-pong/slapback,
chorus/flanger/vibrato/phaser/auto-wah, stereo tools, reverb, cabinet,
exciter, doubler, rotary, Splitter и Mixer. Граф `.sfg` v2 рассчитан на 12 нод
и 48 одноканальных рёбер с явными номерами разъёмов. Редактор позволяет
собирать независимые цепочки, разветвления и смешивание сигналов.

P4 при каждом запуске монтирует штатный слот через 4-bit SDMMC High Speed,
читает `index.json`, проверяет размеры/CRC пакетов `.sfx` и передаёт каталог в
интерфейс. Затем проверяется `AUTORUN.SFG`; валидный граф устанавливается до
старта транспорта Seed3. Ошибка карты не останавливает USB-аудио: остаётся
встроенный резервный каталог из пяти базовых эффектов и двух routing-нод.
Старые `.sfg` v1 автоматически преобразуются P4 при чтении; `.sfx` v1 менять
не требуется. Обновлять нужно обе прошивки: UART передаёт граф v2.

## Управление на дисплее

- Удержание пустой области открывает категории, затем список эффектов с
  примерной нагрузкой Seed3. Неклассифицированные эффекты находятся в OTHER.
- Нажатие на эффект добавляет неподключённую педаль, не меняя другие провода.
- Зелёная точка означает active, красная — bypass.
- Цветные педали располагаются по пяти колонкам; сетка видна только при переносе,
  до последнего занятого ряда плюс один дополнительный. Стрелки показывают направление
  соединений и разъёмы. Раскладка карточек не определяет порядок обработки:
  он вычисляется по проводам.
- Короткое нажатие открывает редактор с крутилками всех параметров профиля
  (до четырёх в текущем формате), значениями и единицами измерения.
- Удержание ноды 1 секунду внутри корпуса открывает Edit, Replace, Information и Delete.
  Оценка CPU и описание находятся в Information, а не на карточке.
  Включение — тап по большой лампе сверху. Отдельной кнопки и номера педали нет.
  Удержание 0,5 секунды (появится белая рамка), затем выход пальца за корпус переносит карточку в другое место сетки
  без изменения аудиосвязей. Пустая ячейка принимает педаль, занятая меняет их местами,
  если оба корпуса помещаются без пересечений. У края экрана работает автопрокрутка.
  Форма корпусов единая: обычный размер 104×198, кабинет 264×198 занимает две ячейки; у текущего
  Cabinet Sim три настоящие ручки Body, Presence, Mix. Модели усилителя пока нет.
- Соединение: два тапа по свободным разъёмам в любом порядке; занятой разъём
  отменяет действие. Удаление: выбрать конец провода, затем тапнуть по пустоте.
  Списков соединений нет. Для разветвления используется Splitter, для сложения
  Mixer. Подробности и иллюстрации — [маршрутизация](SEEDFX_ROUTING_RU.md).
- IN1/OUT1 постоянно зелёные, IN2/OUT2 голубые; внутренние провода разноцветные.
  Параллельные участки разнесены по полосам; прокручивается только поле педалей.
  Входы/выходы и их индикаторы уровня всегда закреплены по краям.
- Редактор с крутилками закрывается по Done и по тапу снаружи карточки.
- Splitter: один вход → два одинаковых выхода. Mixer: два входа → один выход,
  ручки Branch A, Branch B, Master. Второй физический канал остаётся независимым.
- Удержание верхней кнопки `AUDIO SETTINGS` открывает частоту и четыре
  переключателя каналов. Обычный тап не открывает настройки.
- Отключённые физические каналы исчезают с педалборда вместе со стрелками.
  Вернуть их можно в Audio Settings; сохранённая маршрутизация не удаляется.
- Изменение ручек не сбрасывает хвост задержки/реверберации. Значения плавно
  подводятся к целевым примерно за несколько миллисекунд.

Оценки CPU в каталоге ориентировочные. Фактический общий процент продолжает
измеряться на Seed3 и показывается сверху педалборда.

## Разъёмы и реальные педали

Количество входов/выходов относится к конкретному профилю, не к категории
эффекта в целом. Например, у [BOSS SD-1](https://www.boss.info/uk/products/sd-1/)
один вход/выход и ручки Drive/Tone/Level, а
[BOSS DD-8](https://www.boss.info/global/products/dd-8/) имеет стереоразъёмы.
[MXR Phase 90](https://www.jimdunlop.com/mxr-phase-90/) — пример педали с одной
основной ручкой: больше параметров не всегда означает более реалистичный профиль.
Наши DSP-профили — собственные алгоритмы, не точные эмуляции этих моделей.

## Память P4 и проверка интерфейса

`components/p4_lvgl_memory` выделяет LVGL-объекты и задачи рисования только
в PSRAM. Возврата к внутренней памяти при её нехватке нет. Для DMA/ядра
зарезервировано 64 КиБ SRAM; формат SPI-кадра остаётся 544 байта.
ESP-IDF 5.5.5 использует временный DMA-буфер для такого кадра из-за выравнивания
cache line P4. Общий malloc интерфейса раньше вытеснял этот буфер и приводил
к `Failed to allocate priv RX buffer` и последующему Load access fault.

При существующем `sdkconfig` убедитесь, что `CONFIG_LV_USE_CUSTOM_MALLOC=y`,
`CONFIG_LV_USE_CLIB_MALLOC` отключён и
`CONFIG_SPIRAM_MALLOC_RESERVE_INTERNAL=65536`. Для нового проекта это задано
в `sdkconfig.defaults`.

`python tools/host/build_tests.py` проверяет добавление/удаление, скрытые каналы,
крутилки, моно-маршрутизацию и сохранение хвоста задержки на ПК.
Команда консоли P4 `ui stress` временно рисует цепочки 0..12..0 десять раз,
не меняет DSP-граф и возвращает исходный педалборд. Во время этой проверки
касания блокируются. Журнал выводит свободную память и запас стека.

Подробная инструкция и пример параллельных цепочек —
[маршрутизация педалборда](SEEDFX_ROUTING_RU.md).

Текущие ограничения: 12 активных нод, 48 рёбер и до 64 записей каталога.
Это ограничения формата/редактора, а не обещание запустить любое число тяжёлых
эффектов одновременно. Допустимая DSP-нагрузка проверяется отдельно от UI.
