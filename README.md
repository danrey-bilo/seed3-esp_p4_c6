# Seed3 ↔ SPI ↔ ESP32-P4 ↔ USB Audio 2

Текущая версия v0.2.1: **2 входа + 2 выхода, только 24 бит,
44,1 / 48 / 88,2 / 96 кГц**, USB High Speed, штатный Windows `usbaudio2.sys`.
Seed3 задаёт аудиочасы, P4 — SPI master на **20 МГц**.
Оба направления имеют общие часы; формат выбирает ПК.

По USB передаются упакованные PCM24 LE — **3 байта на отсчёт**, 6 байт на
стереокадр. Внутренний API и проверенная SPI-шина сохраняют PCM24 в `int32_t`.
Это уменьшает USB payload на 25%; пропускная способность SPI не меняется.

Настройка и статус текущего профиля: [PCM24-only](docs/PCM24_ONLY_RU.md).
Предыдущая квалификация относится к [v0.2](libraries/p4_uac2_stream_v2/docs/TEST_REPORT_RU.md),
а не автоматически к новым дескрипторам и АЦП.

## Образы и назначение

Для multirate обновляются **обе** платы:

- Seed: `Seed3/firmware/Seed3P4SpiAudio.bin`, ROM DFU, адрес `0x08000000`.
- P4: `ESP32-P4-WIFI6-Touch-LCD-7B/firmware/ESP32P4_Seed3_SPI_UAC2_2x2_Merged.bin`,
  **rev1.x**, адрес `0x2000`, ESP-IDF **5.5.5**.

Используйте соседние `flash.cmd` и `firmware/SHA256SUMS.txt`.
Не обходите несовместимость ревизий через `--force`.

В Seed capture сейчас — **АЦП L/R** (`kUseTestTones = false`). Для диагностики
можно включить синусы 997/1501 Гц этой константой и пересобрать Seed.
Аналоговый выход смешивает местный вход с USB playback с коэффициентом 0,5.
Проверка синусов не является измерением ADC/DAC.

## Задержка и предел частоты

USB-пакет каждые 0,5 мс; запас устройства 1/2/4 мс задаётся API или консолью
при закрытых потоках. По умолчанию 1 мс, округление до блока 32 кадра, минимум
64 кадра. Буфер Windows выбирается в WASAPI exclusive / DAW, независимо.
Тестер `--period min` согласовывает минимум драйвера с целыми кадрами;
для загруженного ПК нужен запас. Это не ASIO и не обещание сквозной задержки 3 мс.
Для прежнего профиля v0.2 на этом ПК квалифицирован WASAPI **10 мс**:
60 секунд capture, 100 open/close, 301 секунда duplex 96k.
Выбор 3 мс доступен, но прежний длинный тест на нём не прошёл.
Результаты нового packed-24 профиля — в отдельном отчёте выше.

192 кГц испытаны при SPI 20 МГц: около 4300 транзакций/с вместо нужных 6000.
Ограничивает полный цикл обмена Seed/P4, не USB HS. В рабочем профиле
192 кГц не объявлены. При 96 кГц нужны 3000 транзакций/с; пакет 288 байт
занимает 34,56% проводного времени на 20 МГц. CPU-нагрузка — отдельная величина.

Seed восстанавливается после перезапуска P4 через timeout/IWDG и новую сессию.
Работающий Seed переводится в DFU командой `seed boot` через P4.
BOOT+RESET остаётся аварийным способом, если приложение/UART недоступны.
