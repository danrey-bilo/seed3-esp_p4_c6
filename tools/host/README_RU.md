# Проверки SeedFX и педалборда на ПК

Тесты компилируют настоящий `seedfx_graph.cpp` и LVGL-интерфейс прошивки.
Заголовки `include/` заменяют только аппаратные зависимости/очередь RTOS.
Поэтому результат не доказывает работу DMA, тачскрина или временные гарантии
аудиопрерываний — они проверяются на платах отдельно.

Нужны Python 3, распакованный Zig 0.14.1 для Windows x86_64 и зависимости
LVGL, загруженные сборкой ESP-IDF в `managed_components/lvgl__lvgl`.
Путь к компилятору можно задать переменной окружения `SEEDFX_ZIG`. По умолчанию:
`.tmp/native-compiler/zig-x86_64-windows-0.14.1/zig.exe`.

Из корня репозитория:

```powershell
$env:SEEDFX_ZIG = 'C:\Tools\zig\zig.exe'
python tools/host/build_tests.py
python tools/test_seedfx_pack.py
```

Все EXE, OBJ, кэши и BMP-снимки настоящего интерфейса остаются в
`.tmp/host-ui`, не в исходниках. Assertions остаются включены независимо от
оптимизации сборки. Повторный запуск использует кэш объектов с проверкой
времени изменения исходников/заголовков.

Покрытие:

- 240 циклов добавления/удаления, предел 12, 16 масок каналов, 100 открытий
  редактора, независимые ручки, отказ без изменения UI при заполненной очереди;
- реальные обработчики выбора соединений, независимые каналы, Splitter/Mixer,
  циклы, стабильные ID и отсутствие автоматического переподключения;
- 1536 плотных стерео/моно/широких схем: никакие параллельные отрезки не накладываются,
  все точки в пределах адаптивной рабочей области; цвета физических пар постоянны;
- два тапа в любом порядке, отказ занятого разъёма, удаление тапом по пустоте,
  включение лампой на карточке и закрытие редактора по внешней области;
- CRC физических пиков АЦП/ЦАП, повреждённые и укороченные строки, маски
  каналов, clipping и максимум 16 неблокирующих UART-записей за poll;
- DSP на четырёх частотах; 64 схемы по 12 нод с обратным порядком ID в массиве
  и сравнением с отдельным скалярным расчётом для всех масок выходов;
- 42 DSP-профиля без NaN/Inf, влияние 14 расширенных параметров, хвост Delay;
- миграция `.sfg` v1, упаковка v2, CRC и отклонение неправильных соединений.

Рендеры: `parallel-routing.bmp`, `patch-selected.bmp`, `physical-meters.bmp`,
`knobs.bmp`, `board-12.bmp`. Это тестовые схемы, не фотографии устройства.
`tools/host/export_previews.ps1` конвертирует снимки в PNG для документации,
не изменяя изображение.
