SEEDFX — готовая папка microSD (.sfx v1, граф .sfg v2)
================================

Скопируйте папку SEEDFX целиком в корень карты FAT32. После включения P4:

1. монтирует встроенный слот microSD по SDMMC 4-bit High Speed;
2. читает index.json;
3. проверяет версию, размер и CRC32 каждого *.sfx;
4. передаёт 42 проверенных профиля в каталог педалборда;
5. проверяет и загружает AUTORUN.SFG.

Если карты нет или отдельный файл повреждён, аудиотракт продолжает запускаться.
Неисправный файл пропускается; при полностью неисправном каталоге используются
пять безопасных встроенных эффектов и Splitter/Mixer.

effects/<категория>/*.json — читаемые исходники описаний.
effects/<категория>/*.sfx  — пакеты, которые читает P4.
presets/*.json             — читаемые исходники пресетов.
presets/*.sfg              — бинарные графы SeedFX.
AUTORUN.SFG                — стартовый граф.
index.json                 — автоматически создаваемый индекс.
SHA256SUMS.txt             — SHA-256 всех готовых файлов.

Пересоздание полного каталога и пакетов из корня репозитория:

  python tools/generate_seedfx_catalog.py
  python tools/seedfx_pack.py --root microSD-ready/SEEDFX

СТАТУС v1: эти пакеты пока содержат описания и параметры встроенных алгоритмов.
Целевой формат должен содержать и исполняемый Cortex-M7-код, загружаемый в RAM
только для активных педалей. Загрузчик такого кода пока не реализован;
существующие .sfx не являются исполняемыми плагинами.

Интерфейс: удержание AUDIO SETTINGS открывает частоту/каналы. Выключенные
каналы и стрелки скрыты. Тап педали открывает крутилки, удержание — действия,
Information и Connections. Тап по разъёму выбирает источник/получателя.
Каждый провод передаёт один канал. Новая педаль не подключается автоматически.
Splitter копирует один вход в два выхода; Mixer смешивает два входа в один
с ручками Branch A, Branch B и Master. Петли обратной связи запрещены.
Выход без провода молчит. Удаление педали удаляет только её провода.

presets/parallel_branches.sfg — пример: IN 1 -> компрессор -> Splitter ->
Overdrive/Delay -> Mixer -> OUT 1; IN 2 -> OUT 2 независимо.
AUTORUN.SFG по умолчанию остаётся пустым педалбордом с IN 1 -> OUT 1,
IN 2 -> OUT 2. Для автозапуска другого пресета скопируйте выбранный .sfg
в SEEDFX/AUTORUN.SFG, сохранив резервную копию предыдущего файла.
После замены AUTORUN его контрольная сумма в SHA256SUMS.txt станет устаревшей;
CRC32 внутри самого графа остаётся корректной.

Новые прошивки читают старые графы v1 с автоматическим преобразованием.
Старая прошивка Seed3 не принимает v2: обновляйте обе платы вместе.
Старую карту с 40 эффектами можно оставить: P4 добавляет Splitter/Mixer
в каталог самостоятельно. Для новых файлов/примера скопируйте эту папку.
