SEED3 + ESP32-P4: готовая структура microSD
===========================================

1. Карта должна быть FAT32.
2. Скопируйте папку SEEDFX целиком в корень карты.
3. Итоговый путь должен быть /SEEDFX/index.json.

AUTORUN.SFG — пустой безопасный педалборд (прямой стереопроход).
effects/core — по одному пакету на каждый тип эффекта.
presets — один файл на схему из нескольких нод.

JSON оставлен рядом с бинарными файлами, чтобы проект было удобно читать и
редактировать. Прошивка должна использовать проверенные .sfx/.sfg файлы.
