# Интерфейс Seed3 / ESP32-P4

Экран рассчитан на дисплей 1024×600 и LVGL 9.5.0. Проект редактируется в EEZ Studio без EEZ Flow.

## Содержимое

- меню окон открывается свайпом от верхней кромки вниз;
- окно `MONITOR` содержит текущую аудиотелеметрию;
- пустой макет `PEDALBOARD` содержит расширенное рабочее поле и два узких
  блока `IN` / `OUT` по краям;
- окно `SETTINGS` содержит системные настройки поведения дисплея;
- верхний `PEDALBOARD` switch показывает подтверждённый режим `ON/BYPASS`
  только с ПК, когда этот режим разрешено менять;
- удержание `IN` или `OUT` открывает раздельные настройки каналов и одну общую
  для входа и выхода частоту;
- включённые блоки и каналы обозначаются зелёным, выключенные — серым;
- интерфейс использует плоское 2D-оформление без теней;
- справа сверху — загрузка CPU Seed3 в процентах и компактная полоса заполнения;
- четыре вертикальных индикатора: `IN 1`, `IN 2`, `OUT 1`, `OUT 2`;
- текущий уровень и peak для каждого канала;
- единая подтверждённая частота Seed3 и отдельные состояния input/output;
- формат, состояние SPI и источник аудиочасов;
- входные каналы выделены зелёным, выходные — синим.

Рабочая прошивка сама инициализирует GT911 через BSP Waveshare. Навигационный
свайп и полупрозрачный индикатор касания обновляются 10-мс LVGL-таймером по
координатам pointer-устройства и не требуют включения многоточечного
`LV_USE_GESTURE_RECOGNITION`.

## Идентификаторы для кода

| Назначение | EEZ identifier |
|---|---|
| Загрузка Seed3 | `bar_seed_cpu`, `label_seed_cpu` |
| Вход 1 | `bar_meter_in_1`, `label_meter_in_1` |
| Вход 2 | `bar_meter_in_2`, `label_meter_in_2` |
| Выход 1 | `bar_meter_out_1`, `label_meter_out_1` |
| Выход 2 | `bar_meter_out_2`, `label_meter_out_2` |
| Общая частота у входа | `label_capture_rate`, источник `sample_rate` |
| Та же общая частота у выхода | `label_playback_rate`, тот же `sample_rate` |
| Состояние входа | `label_capture_status` |
| Состояние выхода | `label_playback_status` |
| Нижняя строка состояния | `label_footer_status` |

Индикаторы имеют диапазон 0…100. Преобразование dBFS в заполнение рекомендуется выполнять в модели данных P4, а не в callback USB/SPI. Обновление GUI достаточно делать с частотой 30–60 Гц, с быстрым подъёмом и более медленным спадом уровня.

В рабочей прошивке экран реализован компонентом
`components/p4_audio_dashboard`; проект EEZ и
`preview.svg` служат редактируемым эталоном компоновки. Все числовые поля
частоты получают только подтверждённый физический такт Seed3 из общего
`sample_rate`. Без ПК частота выбирается локально и сохраняется в NVS. После
начала USB enumeration её владелец — Windows, поэтому экранные кнопки становятся
read-only до отключения USB.

При включённом `AUTO WINDOW SWITCH` рабочая прошивка выбирает `PEDALBOARD` без
ПК и `MONITOR` при появлении USB SOF. Настройка сохраняется в NVS; при её
отключении выбранное вручную окно не меняется вслед за USB.

Макет педалборда в текущей версии ещё не создаёт DSP-ноды. Состояние верхнего
переключателя уже передаётся Seed3 и подтверждается обратно, но при пустом
графе `ON` и `BYPASS` дают одинаковый звук. Переключатели отдельных входов и
выходов уже управляют реальными масками Seed3 и сохраняются в NVS. При переходе
с монитора вычисление и отрисовка peak levels приостанавливаются.
