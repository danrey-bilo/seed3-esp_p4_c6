# ESP32-P4 · SPI ↔ USB Audio 2

[← Главная](../README.md) · [Подключение](../docs/wiring.md) · [Прошивка](../FLASHING_RU.md)

Проект ESP-IDF **5.5.5** для **ESP32-P4-WIFI6-Touch-LCD-7B rev1.x**.
Рабочий профиль v0.2.1: USB HS UAC2, **2 capture + 2 playback**, только
**24-битный packed PCM**, 44,1 / 48 / 88,2 / 96 кГц.

## Архитектура

[main/main.c](main/main.c) содержит только порядок запуска компонентов.
Проверенный SPI master на 20 МГц, READY и управляющий UART вынесены без
изменения алгоритма в компонент
[seed3_spi_transport](components/seed3_spi_transport). Seed задаёт аудиочасы. Компонент
[p4_uac2_stream](components/p4_uac2_stream/README_RU.md) переносит PCM
между кольцами приложения и USB: DMA, prefill, explicit feedback и восстановление
endpoint. PCM conversion выполняется в задаче, не в USB ISR.

[p4_audio_dashboard](components/p4_audio_dashboard) запускает официальный BSP
Waveshare и LVGL 9.5. Интерфейс обновляется отдельной задачей с низким
приоритетом: четыре peak-индикатора, CPU Seed3, единый подтверждённый clock и состояния
capture/playback. Свайп сверху вниз открывает меню окон с монитором и пустым
макетом педалборда. Верхний переключатель управляет подтверждаемым Seed3
состоянием `ON/BYPASS`. Без ПК педалборд принудительно включён и локальный
профиль частоты берётся из NVS; при USB-подключении общий clock передаётся
Windows, а локальный выбор блокируется. Когда монитор закрыт, расчёт peak
levels и его обновление останавливаются. Аудиозадачи передают только атомарные
снимки значений. Владение clock, NVS и переходы `LOCAL/WINDOWS` находятся в
[p4_audio_control](components/p4_audio_control), а не в основном приложении.

![Путь звука Seed3 → P4 → Windows](../docs/assets/audio-overview.svg)

| Интерфейс | Назначение |
| :--- | :--- |
| GPIO2 / 3 / 4 / 5 | SCLK / MOSI / MISO / CS |
| GPIO28 | READY от Seed |
| GPIO30 / 31 | RX / TX управляющего UART |
| USB-A J1 | USB HS аудио, только через data-only адаптер с разрывом VBUS |
| USB TO UART | Прошивка и консоль, сейчас COM6 |

Полная проводка и обязательные ограничения питания — [здесь](../docs/wiring.md).
Дисплей входит в профиль; Wi-Fi, SD и отдельная прошивка C6 пока отключены.

## Сборка и прошивка

Из этой папки на подготовленном стенде:

```powershell
.\build.cmd
.\flash.cmd COM6
```

Скрипт сборки активирует установленный ESP-IDF 5.5.5. Используется собственный
компонент `p4_uac2_stream`; зависимости зафиксированы в
[dependencies.lock](dependencies.lock). Готовые образы — в [firmware](firmware).

| Образ | Offset |
| :--- | :--- |
| `ESP32P4_Seed3_SPI_UAC2_2x2_Merged.bin` | **0x2000**, содержит всё необходимое |
| `bootloader.bin` | 0x2000 |
| `partition-table.bin` | 0x8000 |
| `seed3_p4_spi_uac2.bin` | 0x10000 |

Выберите merged-образ **либо** набор отдельных образов. `flash.cmd` уже
использует правильный offset и ROM `--no-stub` / 115200 baud.
Не обходите проверку ревизии через `--force`.

## Настройка и диагностика

На Windows используются `usbaudio2.sys` и WASAPI. Для смены sample rate
закройте оба потока. USB передаёт 3 байта/отсчёт; внутренний API — `int32_t`
PCM24 left-aligned. Запас устройства: `buffer 1|2|4` при закрытых потоках.

При отсутствии USB-хоста частоту можно выбрать на педалборде; значение
сохраняется как локальный профиль. С начала USB enumeration владельцем частоты
становится Windows, поэтому кнопки на экране переходят в read-only. После
реального отключения действует 750-мс фильтр кратких bus reset, затем
восстанавливаются локальная частота и принудительный `PEDALBOARD ON`.
Физическое отключение определяется по остановке SOF, а не по потенциально
устаревшим флагам TinyUSB; повторное подключение не требует reset платы.

Переключатели `IN1/IN2` и `OUT1/OUT2` передают реальные маски Seed3 и
сохраняются в NVS. USB для совместимости с Windows остаётся 2×2: отключённые
каналы передают/принимают нули, а Seed пропускает их PCM-конвертацию и
микширование. Диагностическая команда: `channels CAPTURE PLAYBACK`, маски 0…3.

Все экраны получают частоту из одного источника — подтверждённого
`source_sample_rate` Seed3. Поля `capture_sample_rate` и
`playback_sample_rate` остаются в `p4_uac2_get_stats()` только для журналов и
диагностики выбора Windows; UI их не смешивает с физическим clock.

Ожидаемые признаки работы: `mounted=1`, `hs=1`, совпадение `rate` и `seed`,
отсутствие прироста CRC/sequence и ошибок USB в непрерывном потоке.
При старте/закрытии накопительные счётчики могут отличаться от нуля —
оценивайте их прирост отдельно от установившейся передачи.
