# p4_audio_dashboard

Изолированный компонент интерфейса дисплея 1024×600 и GT911:

- страницы `MONITOR` и `PEDALBOARD`;
- четыре индикатора уровня и CPU Seed3;
- единая частота из `audio_dashboard_status_t.sample_rate`;
- неблокирующая очередь команд частоты, `ON/BYPASS` и масок каналов;
- меню окон, открываемое только свайпом сверху вниз.

Короткое нажатие в верхней области ничего не открывает. Постоянной подсказки
`SWIPE DOWN` на экране нет. GUI работает в низкоприоритетной задаче и получает
только атомарные снимки; LVGL не вызывается из USB/SPI ISR.

Переключатели `IN1/IN2` и `OUT1/OUT2` управляют реальными масками тракта.
Команда схлопывается до последнего состояния, а подтверждённый снимок control
слоя повторно синхронизирует цвет и положение переключателей.

Публичный API — [audio_dashboard.h](include/audio_dashboard.h).
