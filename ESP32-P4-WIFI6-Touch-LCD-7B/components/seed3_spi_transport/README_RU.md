# seed3_spi_transport

Проверенное транспортное ядро Seed3 ↔ ESP32-P4 вынесено из `main` без
изменения алгоритма передачи:

- SPI mode 0, 20 МГц, READY handshake;
- фиксированный физический DMA-кадр 544 байта, CRC и sequence control;
- SPSC-кольца UAC2 capture/playback;
- управляющий UART Seed3 и диагностическая консоль;
- телеметрия уровней, CPU и ошибок.

Wire protocol v2 передаёт 32 или 64 действительных стереокадра в фиксированной
544-байтной DMA-транзакции. В свободных управляющих битах `status` P4→Seed
передаются маски двух входов и двух выходов. Перед отправкой P4 зануляет
отключённые playback-каналы, а после проверки CRC зануляет отключённые
capture-каналы.

- `BALANCED`: 32 frames на 44,1/48 кГц, 64 на 88,2/96 кГц;
- `LOW LATENCY`: 32 frames на всех частотах;
- `LOCAL`: автоматический control-only кадр около 50 раз/с, без аудио.

Компонент не решает, кто владеет частотой. Он получает требуемый общий clock
из `p4_uac2_stream`, а состояние педалборда — через короткий API
`p4_audio_control`. Это сохраняет транспорт стабильным при развитии UI и DSP.

Публичный API — [seed3_spi_transport.h](include/seed3_spi_transport.h).

Для стендовой проверки доступна команда `channels CAPTURE PLAYBACK`, где
каждая маска имеет значение 0…3 (`1` — CH1, `2` — CH2, `3` — оба).
Профиль меняется командами `transport balanced` и `transport low`.
